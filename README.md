# williamthe5thc.github.io

The root of my GitHub Pages address. It does three small jobs for the
portfolio at https://williamthe5thc.github.io/Portfolio/ :

- `index.html` sends visitors from the bare address to the portfolio.
- `robots.txt` tells search engines where the portfolio's sitemap is.
  Crawlers only read robots.txt at the root of a host, so it can't live in
  the Portfolio repo.
- `llms.txt` points AI assistants to the portfolio's full summary.

Other repos' Pages sites (for example `/Portfolio/`) are served by those
repos, not this one.
